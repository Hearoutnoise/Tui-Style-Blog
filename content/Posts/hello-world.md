# Hello World

Welcome to my self-hosted blog.

This site is a static page. The file list you see is generated from the `content/` directory. To add a new article, drop a Markdown file into a `content/` folder and run `node build.js` again.

## What you can do

- Add a file node under any directory
- Set a `title`, a `date` and a list of `tags`
- Write the body in Markdown
- Link a `href` to open an external page instead of inline content
