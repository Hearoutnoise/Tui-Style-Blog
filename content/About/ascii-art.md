# ASCII Art

ASCII art is a graphic design technique that builds an image out of printable text characters. Instead of pixels, it arranges letters, numbers, and symbols into a grid that the eye reads as a picture.

Character ramps go from light to dark, for example.

` .:-=+*#%@`

A dense character such as `@` stands for a bright area, while a light one such as `.` stands for a dark area. By sampling an image's luminance and mapping each cell to a character, a program can turn any picture into ASCII art.

This site uses ASCII art in its page backgrounds and in the file manager to give a retro terminal feel.
