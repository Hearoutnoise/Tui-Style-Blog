# The Dracula Theme

The Dracula theme is a dark color palette used by code editors, terminals, and applications. It is meant to be comfortable over long sessions, with soft, warm contrast that reduces eye strain.

The palette is built from a small set of colors.

- Background `#282A36`
- Current Line `#44475A`
- Foreground `#F8F8F2`
- Comment `#6272A4`
- Cyan `#8BE9FD` · Green `#50FA7B` · Orange `#FFB86C`
- Pink `#FF79C6` · Purple `#BD93F9` · Red `#FF5555` · Yellow `#F1FA8C`

The seven accent colors drive syntax highlighting, while the four neutral tones define the surface and the text. This whole site is styled with the same palette.
